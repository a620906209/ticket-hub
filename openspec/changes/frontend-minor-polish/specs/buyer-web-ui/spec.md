## MODIFIED Requirements

### Requirement: 前端導覽處理未知網址並在換頁時回到頁首
前端路由 SHALL 將沒有對應路由的網址導回活動列表頁，不顯示空白頁面。一般換頁 SHALL 捲動到頁首；只改變 `step` query 的導覽（同一路徑、其他 query 與 hash 相同，例如活動詳情頁進入或離開確認步驟）MUST NOT 由路由捲動，焦點與捲動交由頁面處理，此規則優先於下一句，瀏覽器上一頁／下一頁只改變 `step` 時也不還原記錄的捲動位置；瀏覽器上一頁／下一頁（只改 `step` 的導覽除外）SHALL 還原瀏覽器記錄的捲動位置。資料非同步載入的頁面在導覽完成當下高度可能不足以捲到記錄的位置，前端 SHALL 等到頁面高度足以捲到該位置後才還原；等待最多 3 秒，以獨立計時器計算，不因畫面未更新而延長。逾時後仍捲向記錄的位置，頁面不夠高時停在可捲到的最低處。還原時 SHALL 使用瀏覽器記錄的完整位置（含水平位置），高度是否足夠只以垂直位置判斷。等待期間若使用者以滑鼠滾輪、觸控或鍵盤捲動頁面，或又有任何導覽完成（包括連續多次快速導覽、只改變 `step` query 的導覽、重複前往目前頁面；被 guard 中止而未完成的導覽不算），前端 MUST 放棄這次還原，且放棄後 MUST NOT 再捲到這次記錄的位置，避免把使用者拉回舊位置。連續導覽時，只有最後一次導覽可以還原它自己記錄的位置。此規則由前端路由統一處理，會員前台、主辦方後台與平台管理的頁面皆適用。

#### Scenario: 開啟不存在的網址
- **WHEN** 使用者開啟沒有對應路由的網址（例如 `/no-such-page/deep`）
- **THEN** 前端導向活動列表頁

#### Scenario: 換頁回到頁首
- **WHEN** 使用者在已捲動的頁面點選連結前往另一頁
- **THEN** 新頁面從頁首開始顯示；若為瀏覽器上一頁／下一頁，則還原瀏覽器記錄的捲動位置（只改變 `step` query 的導覽除外，見 BW-NAV-STEP-001）

#### Scenario: BW-NAV-RESTORE-001 上一頁回到非同步載入的頁面時還原原位置
- **WHEN** 使用者在資料非同步載入的頁面（例如「我的訂單」）捲到下方後前往另一頁，再按瀏覽器上一頁；返回時頁面資料在導覽完成後才載入（3 秒內）
- **THEN** 資料載入後頁面捲到離開前記錄的位置，而不是停在較接近頁首的位置

#### Scenario: BW-NAV-RESTORE-002 等待逾時仍捲向記錄的位置
- **WHEN** 瀏覽器上一頁回到的頁面在 3 秒內高度仍不足以捲到記錄的位置
- **THEN** 逾時後頁面捲向記錄的位置，停在目前可捲到的最低處

#### Scenario: BW-NAV-RESTORE-003 等待期間使用者捲動或再次導覽時不還原
- **WHEN** 瀏覽器上一頁後、還原前，使用者以滑鼠滾輪、觸控或鍵盤捲動頁面，或又有任何導覽完成（包括連續多次導覽、只改變 `step` query 的導覽、重複前往目前頁面；被 guard 中止而未完成的導覽不算）
- **THEN** 前端不再把頁面捲到該次記錄的位置；連續導覽時只有最後一次導覽的捲動規則生效

#### Scenario: BW-NAV-STEP-001 切換確認步驟不捲回頁首
- **WHEN** 導覽只改變 `step` query（例如 `/events/{id}` 與 `/events/{id}?step=confirm` 之間，不論是否有瀏覽器記錄的捲動位置）
- **THEN** 路由不捲動頁面；路徑、其他 query 或 hash 不同的導覽維持原本的捲動規則
